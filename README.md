# SIH Digital Co-Pilot: AI-Powered Precise Train Traffic Control

This repository contains the infrastructure and AI Decision Support System for Indian Railway Section Controllers. It is designed to predict track conflicts and provide mathematically optimized re-routing recommendations in real-time.

## Architecture

The system operates as a closed-loop digital twin:
**Python Simulator** (Fake IRCTC) $\rightarrow$ **Redis Streams** (Message Broker) $\rightarrow$ **FastAPI** (WebSocket Bridge) $\leftrightarrow$ **Next.js** (Controller Dashboard)

## Running

```bash
docker compose up --build
```

Dashboard on `http://localhost:3000`, WebSocket bridge on `http://localhost:8000`.

### Teardown

```bash
docker compose down -v
```

Redis holds no durable state: the simulator rebuilds topology, fleet, and epoch
on every boot, and clients are fenced to the current epoch. `-v` is the default
teardown so a stray anonymous volume cannot reintroduce cross-run state.

## Data Contracts

All microservices communicate via Redis using strict JSON payloads. 

 1. Global Simulation Tick (`train:clock`)
Authoritative tick to sync map rendering and temporal data across all clients.
```json
{
  "event_type": "SIMULATION_TICK",
  "timestamp": 1722643200000,
  "tick_id": 4120,
  "time_multiplier": 5,
  "active_train_count": 42,
  "network_health_score": 87.4
}

2. Live Train State & Telemetry (train:telemetry)
Emits topological railway state, block data, and delay deltas.

{
  "event_type": "TRAIN_TELEMETRY",
  "train_id": "12626",
  "train_name": "Kerala Express",
  "train_type": "EXPRESS", 
  "priority_weight": 9.5, 
  "current_section_id": "NDLS-AGC-04",
  "current_block_id": "BLK-108A",
  "coordinates": { "lat": 28.6139, "lng": 77.2090 },
  "speed_kmh": 110.5,
  "max_allowed_speed_kmh": 130.0,
  "schedule_status": "DELAYED",
  "delay_seconds": 420,
  "next_station_id": "MTJ",
  "eta_next_station": 1722644100000,
  "signal_aspect": "YELLOW"
}

3. Predicted Conflict Event (conflict:alert)
Generated by the AI Engine when spatial-temporal overlaps are predicted at junctions or single-track sections.

{
  "event_type": "CONFLICT_PREDICTED",
  "conflict_id": "CONF-8902",
  "severity": "CRITICAL",
  "predicted_time_to_conflict_seconds": 360,
  "location": {
    "section_id": "NDLS-AGC-04",
    "junction_id": "JNC-PALWAL-02",
    "track_id": "TRK-DOWN-MAIN"
  },
  "conflicting_train_ids": ["12626", "12002"],
  "root_cause": "Cascading delay on Train 12626 causing block starvation at Junction Palwal.",
  "estimated_cascading_impact_minutes": 45
}

4. AI Dispatch Advisory Payload (dispatch:recommendation)
Prioritized resolution strategies generated by the OR Engine via constraint programming.

{
  "event_type": "DISPATCH_RECOMMENDATION",
  "conflict_id": "CONF-8902",
  "scenarios": [
    {
      "scenario_id": "OPT-1",
      "action": "Hold Freight Train 402 at Loop Line",
      "network_impact": "Express 12626 delayed by 0 mins. Freight 402 delayed by 45 mins.",
      "score": 0.88
    },
    {
      "scenario_id": "OPT-2",
      "action": "Hold Express 12626 at Main Line",
      "network_impact": "Express 12626 delayed by 15 mins. Freight 402 delayed by 0 mins.",
      "score": 0.32
    }
  ]
}

5. Controller Action (dispatch:action)
Emitted by the Next.js UI back to the Python Simulator to execute the chosen intervention.

{
  "event_type": "CONTROLLER_ACTION",
  "conflict_id": "CONF-8902",
  "scenario_id": "OPT-1",
  "timestamp": 1722643215000
}
